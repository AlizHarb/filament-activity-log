# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and welcoming. Harassment, personal attacks, discrimination, and disclosure of another person's private information are not acceptable.

Report conduct concerns privately to `harbzali@gmail.com`. Reports will be reviewed fairly and confidentially.
